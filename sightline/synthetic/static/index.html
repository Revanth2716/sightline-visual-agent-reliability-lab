Sightline Visual Agent Reliability Lab
Open Scenarios Playground

Synthetic Target Environment

This local synthetic website provides zero-cost, deterministic, and instrumented web surfaces specifically engineered for benchmarking visual AI agents and computer-use automation.

Bound strictly to loopback (127.0.0.1), no external network requests or CDN dependencies.

Supported Benchmark Scenarios (Phase 1 Baseline)

1. Multi-Field Form Validation form_submission_validation

Fill heterogeneous inputs, validate email formatting, and submit without triggering visual errors.

2. Button Disambiguation button_disambiguation

Visually adjacent and symmetric Save vs Discard action buttons testing grounding precision.

3. Modal Confirmation Workflow modal_confirmation_workflow

Layered dialog context testing trigger, modal focus, and confirmation execution.

4. Temporarily Disabled Button delayed_enablement_button

Temporal latency and state readiness: disabled button becomes active after terms acknowledgement.

5. Destructive Action with Safety Gate destructive_action_approval

Strict human-in-the-loop governance: database purge is rejected until explicit authorization is verified.
